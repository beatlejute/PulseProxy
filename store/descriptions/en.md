# PulseProxy VPN - Chrome Web Store Description (English)

## Short Description (132 characters max)
Simple proxy switcher with presets, authentication, and multi-language support

## Full Description

PulseProxy VPN is a powerful yet simple browser extension that helps you manage and switch between multiple proxy servers with ease.

### 🚀 Key Features

• **Multiple Proxy Types** - Support for HTTP, HTTPS, SOCKS4, and SOCKS5 proxies
• **Proxy Authentication** - Built-in support for username/password authentication
• **Smart Presets** - Create and manage proxy presets with domain-specific rules
• **Domain Matching** - Exact domain matching and wildcard subdomain support (*.example.com)
• **Ignore List** - Define domains that should bypass the proxy
• **Proxy All Sites** - Option to route all traffic through proxy
• **Settings Sync** - Synchronize your settings across devices using Chrome sync
• **Multi-language** - Available in 8 languages: English, German, Spanish, French, Japanese, Portuguese, Russian, and Chinese

### 🎯 Perfect For

- Developers testing applications across different regions
- Privacy-conscious users who want control over their traffic
- Remote workers accessing geo-restricted resources
- Anyone who needs to switch between multiple proxies quickly

### 🔒 Privacy First

- NO data collection or tracking
- All settings stored locally on your device
- Open source - review the code yourself
- No external network requests

### 📖 How to Use

1. Click the PulseProxy icon in your toolbar
2. Add your proxy server details
3. Create presets for different use cases
4. Toggle the connection to activate

### 💡 Tips

- Use wildcards (*.domain.com) to match all subdomains
- Create separate presets for work, personal, and testing
- Enable Chrome Sync to use your settings on multiple devices

### 🌐 Supported Proxy Types

- HTTP Proxy
- HTTPS Proxy  
- SOCKS4 Proxy
- SOCKS5 Proxy
