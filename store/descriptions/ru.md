# PulseProxy VPN - Описание для Chrome Web Store (Русский)

## Краткое описание (до 132 символов)
Простой переключатель прокси с пресетами, аутентификацией и поддержкой 8 языков

## Полное описание

PulseProxy VPN — мощное и простое расширение для управления прокси-серверами и быстрого переключения между ними.

### 🚀 Возможности

• **Множество типов прокси** — Поддержка HTTP, HTTPS, SOCKS4 и SOCKS5
• **Аутентификация** — Встроенная поддержка авторизации по логину/паролю
• **Умные пресеты** — Создавайте пресеты с правилами для конкретных доменов
• **Сопоставление доменов** — Точное совпадение и поддержка wildcard (*.example.com)
• **Список исключений** — Определите домены, которые должны обходить прокси
• **Режим "Все сайты"** — Возможность направить весь трафик через прокси
• **Синхронизация** — Синхронизируйте настройки между устройствами через Chrome sync
• **Мультиязычность** — 8 языков: английский, немецкий, испанский, французский, японский, португальский, русский и китайский

### 🎯 Подходит для

- Разработчиков, тестирующих приложения из разных регионов
- Пользователей, заботящихся о приватности
- Удалённых работников с доступом к гео-ограниченным ресурсам
- Всех, кому нужно быстро переключаться между прокси

### 🔒 Приватность прежде всего

- НЕ собираем и НЕ отслеживаем данные
- Все настройки хранятся локально на вашем устройстве
- Открытый исходный код — проверьте сами
- Никаких внешних сетевых запросов

### 📖 Как использовать

1. Нажмите на иконку PulseProxy на панели инструментов
2. Добавьте данные вашего прокси-сервера
3. Создайте пресеты для разных сценариев
4. Включите подключение для активации

### 💡 Советы

- Используйте wildcard (*.domain.com) для всех поддоменов
- Создавайте отдельные пресеты для работы, личного использования и тестирования
- Включите Chrome Sync для использования настроек на нескольких устройствах

### 🌐 Поддерживаемые типы прокси

- HTTP Proxy
- HTTPS Proxy  
- SOCKS4 Proxy
- SOCKS5 Proxy
