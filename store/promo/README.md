# Промо материалы для PulseProxy VPN

Эта папка содержит промо материалы и описания для Chrome Web Store на разных языках.

## Структура файлов

### Основные файлы описаний:
- `description_ru_corrected.md` - Исправленное русское описание (без избыточных ключевых слов)
- `description_en_corrected.md` - Исправленное английское описание
- `description_es_corrected.md` - Исправленное испанское описание
- `description_de_corrected.md` - Исправленное немецкое описание
- `description_fr_corrected.md` - Исправленное французское описание
- `description_ja_corrected.md` - Исправленное японское описание
- `description_pt_corrected.md` - Исправленное португальское описание
- `description_zh_corrected.md` - Исправленное китайское описание

### Особенности исправленных описаний:
1. Убраны избыточные ключевые слова (списки сайтов)
2. Удалены "отзывы пользователей", которые Chrome Web Store воспринял как спам
3. Более естественное и информативное описание
4. Соответствие правилам Chrome Web Store
5. Акцент на функциональность и преимущества без спама

## История изменений

### 4 февраля 2026
- Созданы исправленные описания после отказа Chrome Web Store
- Причина отказа: "Избыточные ключевые слова в описании продукта"
- Удалены: списки сайтов, отзывы пользователей, избыточное перечисление

## Использование

Эти описания можно использовать для:
1. Обновления описания в Chrome Web Store
2. Маркетинговых материалов
3. Документации
4. Переводов на другие языки
